# Changelog

Releases are tagged `vX.Y.Z` on this repository and carry the agent binaries as assets. Router and agent have their own
version numbers; this table maps them. Details and the German summary are in each release's notes.

| Tag | Date | Router | Agent | What changed |
|---|---|---|---|---|
| [v0.5.1](https://github.com/psewar/skirnir/releases/tag/v0.5.1) | 2026-09-25 | 0.1.7 | 0.9.1 | Legacy agent path removed: the token WebSocket tunnel (`/v1/tunnel/<node>`) is gone from the router, the agent no longer has an HTTP heartbeat mode (`tunnel.enabled`, `router.interval_s/timeout_s`) and no longer reads the old `mimir:` block (use `secret_store:`); `router.token` remains only for the TLS proxy. `POST /v1/heartbeat/<node>` stays as a token-protected lever for tests and diagnostics. The updater now runs `check-config` with the new binary before swapping, so a rejected configuration ends as a failed order instead of a restart loop. Plus the deploy and repo hygiene below. |
| (same tag) | | | | Deploy and repo hygiene after the code review: `deploy.py` restarts only after the on-host check passes (was chained behind `\|\|`), pins the SSH host key (`<ops>/known_hosts`), keeps the UI password and the secret-store client secret off command lines, and the deploy manifest no longer records a workstation path or user name. Router unit gets `StateDirectory=` so decision capture works under `ProtectSystem=strict`. Legacy PowerShell agent (`agent/`) and the one-off `tools/split_router.py` removed; self-tests renamed to `test/selftest_*.py`; `requirements.txt`, `requirements-dev.txt`, `SECURITY.md`, this changelog and a GitHub Actions workflow added; design notes carry status banners. |
| [v0.5.0](https://github.com/psewar/skirnir/releases/tag/v0.5.0) | 2026-09-25 | 0.1.6 | 0.9.0 | Agent review fixes: control users lose Modify on the config directory; `/restart-child` needs `X-Agent-Token`; the guard judges load on NVML board power and recognises its own targets after a restart; NVML fallback under the mutex; a module panic stops the service; parked `.old-*` cleaned; config defaults next to `--config`; `secret_store.domain` required; proxy refuses to run without a token; systemd unit allows self-update. |
| [v0.4.1](https://github.com/psewar/skirnir/releases/tag/v0.4.1) | 2026-09-25 | 0.1.6 | 0.8.4 | Router review fixes: model catalog renders again (duplicate `renderModels`), Basic Auth hashing off the event loop with a failure cache and per-address throttle, MQTT connect callback no longer publishes from paho's thread, `tls_set` independent of the username, "Try it" finds its decision by request id, auto role can be enabled at runtime, MAC validation, registry inputs not overwritten while typing. |
| [v0.4.0](https://github.com/psewar/skirnir/releases/tag/v0.4.0) | 2026-09-25 | 0.1.5 | 0.8.4 | Agent updates through the router: `deploy.py --agent` signs a manifest with an operator Ed25519 key; agents verify, download with a one-time token, swap themselves and restart; per-node policy, canary node, rollout loop, HA problems for failures and stalls. |
| [v0.3.3](https://github.com/psewar/skirnir/releases/tag/v0.3.3) | 2026-09-25 | 0.1.4 | 0.7.1 | Decision log persists in `events.jsonl` next to the configuration (2000 entries, compaction); log size selector, filter and scrolling in the UI; quiet heartbeat ack on a closing tunnel. |
| [v0.3.2](https://github.com/psewar/skirnir/releases/tag/v0.3.2) | 2026-09-25 | 0.1.3 | 0.7.1 | Requests wait for a model that is being loaded instead of getting 503 during a model switch (`wait_load`). |
| [v0.3.1](https://github.com/psewar/skirnir/releases/tag/v0.3.1) | 2026-09-25 | 0.1.2 | 0.7.1 | GPU guard: short load gaps no longer reset the high-load counter (`high_load_gap_s`), measured in the stage-2 night run. |
| [v0.3.0](https://github.com/psewar/skirnir/releases/tag/v0.3.0) | 2026-09-24 | 0.1.2 | 0.7.0 | GPU guard for the 12V-2x6 connector: power limit 80 % of the card default, stage 2 after sustained full load, voltage and temperature warnings, opt-out counts as a Home Assistant problem; router side with per-node policy, score penalty and inflight cap. |
| [v0.2.0](https://github.com/psewar/skirnir/releases/tag/v0.2.0) | 2026-09-24 | 0.1.1 | 0.6.0 | GPU sensors in the heartbeat (NVML temperature, power, limits, fan, throttle reasons) plus GPU-Z shared memory (memory and hot-spot temperature, 16-pin power and voltage, PerfCap) via a relay task; Home Assistant entities. |
| [v0.1.0](https://github.com/psewar/skirnir/releases/tag/v0.1.0) | 2026-09-18 | 0.1.0 | 0.5.1 | First public release: roles and tiers, scheduler with busy detection, admission, decision engine, cloud tiers, client identities, web UI, agent with outbound tunnel. |
