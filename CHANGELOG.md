# Changelog

Releases are tagged `vX.Y.Z` on this repository and carry the agent binaries as assets. Router and agent have their own
version numbers; this table maps them. Details and the German summary are in each release's notes.

| Tag | Date | Router | Agent | What changed |
|---|---|---|---|---|
| [v0.8.1](https://github.com/psewar/skirnir/releases/tag/v0.8.1) | 2026-09-26 | 0.2.0 | 0.11.1 | Agent `setup` validates the migrated configuration **before** it stops the old service or moves the directory; if the rewritten file would not load, nothing is changed and the old service keeps running. The pre-0.9.1 block `mimir:` is renamed to `secret_store:` automatically. Errors are printed before the Enter pause so they stay visible in the UAC window. Background: on one node the 0.11.0 setup removed the old service and then failed on the old configuration, leaving the node without an agent. |
| [v0.8.0](https://github.com/psewar/skirnir/releases/tag/v0.8.0) | 2026-09-25 | 0.2.0 | 0.11.0 | **Renamed** to match the product: Python package `skirnir_router`, service and paths `skirnir-router` (`/opt`, `/etc`, `/var/log`, `/var/lib`), agent binary `skirnir-agent`, Windows service `SkirnirAgent` ("Skirnir Agent"), task `SkirnirAgent-GpuzRelay`, Linux `/etc/skirnir-agent`; repo directory `agent-go` is now `agent`. `deploy.py` moves an existing router installation once; the agent keeps finding the old configuration path, service and task names until `setup` has migrated the node. MQTT side renamed as well (base topic `skirnir-router`, discovery node id `skirnir_router`, unique ids `skirnir_router_*`, entity ids `sensor.skirnir_*`); the router clears the old retained topics once, custom entity ids are carried over by an operator script. Agent setup by double-click: the binary elevates itself (UAC), asks for router address, update key and control user, installs or updates the service *Skirnir Agent* (LocalSystem, technical name unchanged) including the GPU-Z relay task, and shows health and fingerprint. `Install-Service.ps1` checked the admin role by the English group name and refused on a German Windows; fixed, script kept for special cases. |
| [v0.7.0](https://github.com/psewar/skirnir/releases/tag/v0.7.0) | 2026-09-25 | 0.1.9 | 0.9.2 | Counters and histograms behind `/metrics` persist in `metrics.json` next to the configuration (a minute after a change and at shutdown), so a deploy no longer resets them; the UI labels them "total" since the recording began and `/admin/state` carries `metrics_since`. Registered agents moved from the overview to their own *Agents* tab (dot while an agent waits for approval). New `monitoring/`: Prometheus (90 d retention) and Grafana with a provisioned Skirnir dashboard as two containers next to the router, secrets from the secret store, certificate shared with the router, `deploy_ct.py`. |
| [v0.6.0](https://github.com/psewar/skirnir/releases/tag/v0.6.0) | 2026-09-25 | 0.1.8 | 0.9.2 | Web UI in English or German (toggle in the header, browser language by default; settings labels come translated from `/admin/config?lang=`); router API messages, cloud skip reasons and Prometheus HELP texts in English (the operator log and Home Assistant texts stay German). Internals: shared circuit breaker for nodes and cloud targets with a pure read-path variant (the HA snapshot and `/metrics` no longer flip breakers), `Node.go_offline`, one env-file parser, one tool-argument parser, constants in one place, `Config.parse` split into sections with runtime defaults from the settings table, background tasks held in `state.TASKS`; ruff runs Bugbear, BLE and RUF006. Agent 0.9.2: `status`/`start`/`stop`/`restart` work without read access to the configuration (control users lost it in 0.9.0). README: the two names, Skirnir and ollama-router. |
| [v0.5.1](https://github.com/psewar/skirnir/releases/tag/v0.5.1) | 2026-09-25 | 0.1.7 | 0.9.1 | Legacy agent path removed: the token WebSocket tunnel (`/v1/tunnel/<node>`) is gone from the router, the agent no longer has an HTTP heartbeat mode (`tunnel.enabled`, `router.interval_s/timeout_s`) and no longer reads the old `mimir:` block (use `secret_store:`); `router.token` remains only for the TLS proxy. `POST /v1/heartbeat/<node>` stays as a token-protected lever for tests and diagnostics. The updater now runs `check-config` with the new binary before swapping, so a rejected configuration ends as a failed order instead of a restart loop. Plus the deploy and repo hygiene below. |
| (same tag) | | | | Deploy and repo hygiene after the code review: `deploy.py` restarts only after the on-host check passes (was chained behind `\|\|`), pins the SSH host key (`<ops>/known_hosts`), keeps the UI password and the secret-store client secret off command lines, and the deploy manifest no longer records a workstation path or user name. Router unit gets `StateDirectory=` so decision capture works under `ProtectSystem=strict`. Legacy PowerShell agent (`agent/`) and the one-off `tools/split_router.py` removed; self-tests renamed to `test/selftest_*.py`; `requirements.txt`, `requirements-dev.txt`, `SECURITY.md`, this changelog and a GitHub Actions workflow added; design notes carry status banners. |
| [v0.5.0](https://github.com/psewar/skirnir/releases/tag/v0.5.0) | 2026-09-25 | 0.1.6 | 0.9.0 | Agent review fixes: control users lose Modify on the config directory; `/restart-child` needs `X-Agent-Token`; the guard judges load on NVML board power and recognises its own targets after a restart; NVML fallback under the mutex; a module panic stops the service; parked `.old-*` cleaned; config defaults next to `--config`; `secret_store.domain` required; proxy refuses to run without a token; systemd unit allows self-update. |
| [v0.4.1](https://github.com/psewar/skirnir/releases/tag/v0.4.1) | 2026-09-25 | 0.1.6 | 0.8.4 | Router review fixes: model catalog renders again (duplicate `renderModels`), Basic Auth hashing off the event loop with a failure cache and per-address throttle, MQTT connect callback no longer publishes from paho's thread, `tls_set` independent of the username, "Try it" finds its decision by request id, auto role can be enabled at runtime, MAC validation, registry inputs not overwritten while typing. |
| [v0.4.0](https://github.com/psewar/skirnir/releases/tag/v0.4.0) | 2026-09-25 | 0.1.5 | 0.8.4 | Agent updates through the router: `deploy.py --agent` signs a manifest with an operator Ed25519 key; agents verify, download with a one-time token, swap themselves and restart; per-node policy, canary node, rollout loop, HA problems for failures and stalls. |
| [v0.3.3](https://github.com/psewar/skirnir/releases/tag/v0.3.3) | 2026-09-25 | 0.1.4 | 0.7.1 | Decision log persists in `events.jsonl` next to the configuration (2000 entries, compaction); log size selector, filter and scrolling in the UI; quiet heartbeat ack on a closing tunnel. |
