# Architecture Decision Records

Why Skirnir is built the way it is. One decision per file, in [MADR 4.0](https://adr.github.io/madr/) format; the rules
are in [ADR-0001](0001-record-architecture-decisions.md). The design documents in [`design/`](../../design/) describe *how*
things work and link here for the *why*.

- New decision: next free number, `docs/adr/NNNN-title-in-kebab-case.md`, in the same PR as the change (or before it as
  `proposed`), named in the PR description.
- Changed decision: a new ADR that supersedes the old one; the old one only changes its status to
  `superseded by ADR-NNNN`. Accepted ADRs are not rewritten.
- ADR-0002 to ADR-0039 were backfilled on 2026-10-30; each names the date it was decided and its source.
